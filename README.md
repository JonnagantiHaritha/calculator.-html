Calculator Website
Overview

The Calculator Website is a simple and responsive web application developed using HTML, CSS, and JavaScript. It allows users to perform basic arithmetic operations through an interactive and user-friendly interface.

Features
Addition, Subtraction, Multiplication, and Division
Clear button to reset calculations
Responsive design for different screen sizes
Attractive user interface
Fast and accurate calculations
Technologies Used
HTML5
CSS3
JavaScript

How to Run the Project
Download or clone the repository.
Open the project folder.
Open Index.html in any web browser.
Use the calculator to perform calculations.
