Project Name: Calculator Website

Description:
A simple and responsive calculator application developed using HTML, CSS, and JavaScript. The calculator performs basic arithmetic operations such as addition, subtraction, multiplication, and division.

Features:
- Addition
- Subtraction
- Multiplication
- Division
- Responsive User Interface
- Easy-to-use Design

Technologies Used:
- HTML5
- CSS3
- JavaScript
